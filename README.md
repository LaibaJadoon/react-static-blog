# Tech Blog - React Static Blog Application

A modern static blog website built with **React** and **Tailwind CSS**, showcasing technology-focused articles in a clean and organized layout. This project uses **React Router** for navigation between pages and includes multiple components like header, footer, post cards, and post detail pages.

---

## 🚀 Features

- 📰 Static blog post list with title, short description, and tags
- 📄 Post detail page with full article content
- 📂 Dropdown menu under "Categories"
- 🔗 Navigation links: Home, PostDetail
- 💡 Clean and minimal UI layout
- 🧩 Built with reusable React components
- 📌 Page routing using React Router
- 🎨 Styled using Tailwind CSS

---

## 📦 Installation

To run this project locally:

1. Clone the repository
```bash
git clone https://github.com/LaibaJadoon/react-tech-blog.git
cd react-tech-blog

2. Install dependencies
Make sure you have Node.js and npm installed.
```bash
npm install

3. Start the development server
bash
npm run dev
